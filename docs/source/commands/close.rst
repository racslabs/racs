.. _CLOSE:

CLOSE
=====

Closes an existing audio stream.


Arguments
---------

+-------------+------------+---------------------------------------------------------------+
| Name        | Type       | Description                                                   |
+=============+============+===============================================================+
| stream_id   | ``string`` | ASCII ID of the audio stream.                                 |
+-------------+------------+---------------------------------------------------------------+

Input
-----

+----------+--------------------------------------------+
| Type     | Description                                |
+==========+============================================+
| ``null`` | N/A                                        |
+----------+--------------------------------------------+


Output
------

+----------+--------------------------------------------+
| Type     | Description                                |
+==========+============================================+
| ``null`` | N/A                                        |
+----------+--------------------------------------------+

Example
-------

.. code-block:: bash

   CLOSE 'vocals'
