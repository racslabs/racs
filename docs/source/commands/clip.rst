.. _CLIP:

CLIP
====

Enforces a hard minimum and maximum amplitude for sample values outside the threshold.

Arguments
---------

+-----------+------------+---------------------------------------------------------+
| Name      | Type       | Description                                             |
+===========+============+=========================================================+
| min       | ``int``    | Minimum amplitude.                                      |
+-----------+------------+---------------------------------------------------------+
| max       | ``int``    | Maximum amplitude.                                      |
+-----------+------------+---------------------------------------------------------+

Input
-----

+----------+-------------------------------------------------------------+
| Type     | Description                                                 |
+==========+==========+==================================================+
| ``s32v`` | PCM buffer.                                                 |
+----------+-------------------------------------------------------------+

Output
------

+----------+-------------------------------------------------------------+
| Type     | Description                                                 |
+==========+==========+==================================================+
| ``s32v`` | Clipped PCM buffer.                                         |
+----------+-------------------------------------------------------------+

Example
-------

.. code-block:: bash

   CLIP -30000 30000
