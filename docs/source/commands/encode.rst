.. _ENCODE:

ENCODE
======

Encodes data in PCM buffer to MP3, Opus, or WAV.

Arguments
---------

+-------------+------------+-----------------------------------------------+
| Name        | Type       | Description                                   |
+=============+============+===============================================+
| mime_type   | ``string`` | MIME type of the audio output.                |
+-------------+------------+-----------------------------------------------+

Supported MIME types
^^^^^^^^^^^^^^^^^^^^

+-----------------+---------------------------+
| MIME type       | Description               |
+=================+===========================+
| ``audio/wav``   | WAV format                |
+-----------------+---------------------------+
| ``audio/mpeg``  | MPEG / MP3 format         |
+-----------------+---------------------------+
| ``audio/mp3``   | MP3 format (alias)        |
+-----------------+---------------------------+
| ``audio/ogg``   | Ogg/Opus format           |
+-----------------+---------------------------+

Input
-----

+----------+-------------------------------------------------------------+
| Type     | Description                                                 |
+==========+==========+==================================================+
| ``s32v`` | PCM buffer.                                                 |
+----------+-------------------------------------------------------------+


Output
------

+---------+----------------------------------------------------+
| Type    | Description                                        |
+=========+====================================================+
| ``u8v`` | The encoded audio data.                            |
+---------+----------------------------------------------------+

Example
-------

.. code-block:: none

   ENCODE 'audio/mp3'
