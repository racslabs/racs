RACS Docs
=============

About RACS
----------
RACS is a distributed, persistent audio cache optimized for time-indexed range queries. It uses a hybrid memory-disk storage model for low-latency ingestion and retrieval, enabling fine-grained access to arbitrary time ranges within large audio archives while minimizing disk I/O.
